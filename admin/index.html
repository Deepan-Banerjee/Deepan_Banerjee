How do I get a token?
  1. On GitHub, open Settings, then Developer settings, then Personal access tokens, then Fine-grained tokens.
  2. Select Generate new token.
  3. For Repository access, select Only select repositories, and select this website's repository.
  4. Under Permissions, set Contents to Read and write.
  5. Generate the token and paste it above. GitHub shows it only once.

The token is the lock on this page. Without a token that can write to the repository, nobody can change the site. Do not share the token.
